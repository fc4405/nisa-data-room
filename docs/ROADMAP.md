# 収益化ロードマップ（月5万円）と、正直な見通し

## 先に結論

- **「完全放置で月5万円」は保証できません。** 検索流入が育つまでに通常3〜6か月かかり、月5万円に届くのは**早くて6〜12か月後**、届かない可能性もあります。
- 金融ジャンルはGoogleが特に厳しく評価する領域（YMYL）です。このサイトは「AIに大量生成させる」設計を避け、**一次情報の事実だけ・数値はサイト内計算・無料ツール・毎日更新データ**で差別化しています。それでも、AI生成コンテンツ量産として扱われるリスクはゼロではありません。
- 一方で、初期コスト（月数百円程度のAPI費用）が小さく、失うものは主に時間です。

## 月5万円はどういう数字か

報酬は「件数 × 単価」です。**単価はASPと時期で大きく変わるため、必ずASP管理画面で最新値を確認してください**（このドキュメントでは仮の単価で計算しています）。

| 仮の単価（1件） | 月5万円に必要な件数 |
| --- | --- |
| 3,000円 | 約17件 |
| 5,000円 | 10件 |
| 10,000円 | 5件 |

イメージ計算（すべて仮定）: 月1万PV → 証券会社ボタンのクリック率3% → 300クリック → 口座開設の成約率5% → 約15件。
つまり **月1万PV前後の検索流入と、口座開設に関心の高い記事（口座選び系）** が、ひとつの目安になります。

## 段階別の目標

| 時期 | やること | 目安 |
| --- | --- | --- |
| 0〜1か月 | SETUP.md を完了。公開・Search Console登録・ASP申請 | 記事9本＋週3本ペース |
| 1〜3か月 | 記事が20〜30本に。インデックス確認。SNS（X等）で記事・ツールを発信 | 月数百〜数千PV |
| 3〜6か月 | 週次レポートで「順位8〜20位のキーワード」を強化。口座選び系記事の充実 | 初成約 |
| 6〜12か月 | 成果の出た記事の更新・関連記事の拡充。ツールの被リンク獲得 | 月1〜5万円 |

## 差別化の設計（このサイトが競合と違う点）

1. **一次情報だけを根拠にする**（`data/facts.yaml` に無い事実はAIが書けない）。
2. **数字を文章で書かず、サイトが計算する**（早見表・ツール。誤記が入り込まない）。
3. **無料シミュレーター3種**（検索されやすく、リンクされやすく、AI文章と見なされにくい）。
4. **毎日自動更新のマーケットデータ**（鮮度シグナル）。
5. **生成過程の公開**（編集方針ページ）と、**PR表示・中立宣言**（信頼性）。

## 収益を伸ばすレバー（効果が大きい順の目安）

1. **口座選び・クレカ積立系の記事を厚くする**（成約に近い検索意図）。ただし「還元率○%」のような変わりやすい数値は手動＋日付つきでのみ。
2. **`data/facts.yaml` を増やす**（AIが書けるトピックの上限は、ここで決まります）。制度改正・証券会社の公式発表を出典つきで追記するほど、質の高い記事が増えます。
3. **SNSでのツール紹介**（検索流入が立ち上がるまでの初期流入）。
4. **複数ASPの案件を比較し、単価の高いほうに差し替える**（`affiliates.yaml` の1行で全記事が切り替わります）。
5. 補助的にGoogle AdSense（金融ジャンルは単価が低めで、審査もあるため優先度は低い）。

## リスクと対策

| リスク | 対策 |
| --- | --- |
| 「大量生成コンテンツ」判定 | 週3本に抑制／類似度チェック／一次情報のみ／ツール・データで独自価値／生成の開示 |
| 誤情報による信頼毀損・法的問題 | 事実は`facts.yaml`限定／LLMによるファクトチェック／品質ゲート／不合格は公開せず下書きへ |
| 景品表示法（ステマ規制） | アフィリエイトリンクを含む記事に自動で「PR」表示。リンクは`rel="sponsored"` |
| 金融商品取引法（無登録の投資助言） | 個別銘柄の売買推奨を禁止語で検出して不採用。免責・注意書きを全ページに表示 |
| 制度改正で情報が古くなる | 週次レポートで事実データの鮮度を警告（90日）。改正時は`facts.yaml`を更新 |
| ASPの審査に落ちる | 運営者情報・プライバシーポリシー・お問い合わせ先を整備。記事数を増やして再申請 |
| APIコストの暴走 | 1回の実行で最大1本、1トピック最大3日試行。Anthropic側で月の利用上限を設定 |
