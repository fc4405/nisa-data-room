新NISAの生涯投資枠は1,800万円までですが、この枠が「いま自分にいくら残っているか」を正しく理解するには、簿価で管理される仕組みを知る必要があります。

この記事では、生涯投資枠の計算方法と、購入・売却によって残高がどう変動するかを解説します。

**この記事で分かること**
- 生涯投資枠は購入時の取得価額（簿価）で計算される
- 成長投資枠は1,200万円まで、全体で1,800万円の上限がある
- 売却すると簿価分が翌年以降に復活し、枠を再利用できる


## 生涯投資枠は簿価で管理される｜時価ではなく取得価額の合計

新NISAでは、非課税で保有できる限度額（生涯投資枠）は1人1,800万円です。そのうち成長投資枠は1,200万円までという上限があります。

この1,800万円という枠は、**購入時の取得価額（簿価）で管理**されます。つまり、あなたが実際に支払った金額の合計で計算され、その後に資産が値上がりしても値下がりしても、枠の残高には影響しません。

**具体例で確認する**

- 100万円分の投資信託を購入した → 生涯投資枠を100万円使った
- その後、資産が150万円に値上がりした → 枠の使用額は100万円のまま（150万円にはならない）
- その後、資産が80万円に値下がりした → 枠の使用額は100万円のまま（80万円にはならない）

つまり、生涯投資枠の残高は「これまでに購入した金額の合計」で決まります。現在の評価額（時価）がいくらであっても、枠の計算には関係しません。

この仕組みを理解していないと、「資産が増えたら枠も減るのでは？」「値下がりしたら枠が戻るのでは？」と誤解してしまいます。生涯投資枠は購入時の簿価で管理される、と覚えておきましょう。


## 成長投資枠1,200万円までのルール｜残りはつみたて投資枠と共通

生涯投資枠1,800万円の内訳には、もう一つ重要なルールがあります。

**成長投資枠は1,200万円まで**という上限です。残りの600万円（1,800万円 - 1,200万円）は、つみたて投資枠だけで使うことになります。

これを整理すると、次のような使い方ができます。

**生涯投資枠の使い方パターン**

- パターン①：つみたて投資枠600万円 + 成長投資枠1,200万円 = 合計1,800万円
- パターン②：つみたて投資枠1,800万円 + 成長投資枠0万円 = 合計1,800万円
- パターン③：つみたて投資枠1,000万円 + 成長投資枠800万円 = 合計1,800万円

成長投資枠は1,200万円を超えて使うことはできませんが、1,200万円未満で止めることは自由です。その場合、つみたて投資枠を多く使えます。

**よくある誤解**

「成長投資枠を使わないと損では？」と考える人もいますが、成長投資枠を使うかどうかは投資方針の問題です。つみたて投資枠だけで1,800万円まで使うこともできます。

成長投資枠とつみたて投資枠の違いを整理したい方は、[つみたて投資枠と成長投資枠は両方使える？併用のルールと使い分け例](/articles/nisa-tsumitate-seicho-ryouhou-tsukau/)も参考にしてください。


## 売却すると簿価分が翌年以降に復活する仕組み

新NISAでは、NISA口座で保有する商品を売却すると、その簿価分の枠が翌年以降に再利用できます（同じ年内には復活しません）。

**売却と枠の復活の流れ**

1. 100万円分の投資信託を購入 → 生涯投資枠を100万円使った（残り1,700万円）
2. その後、資産が150万円に値上がり
3. 全額を売却（150万円で売却） → 売却代金は150万円だが、復活する枠は購入時の簿価100万円分
4. 翌年1月 → 生涯投資枠が100万円復活し、再び1,800万円に戻る

ここでも、復活する枠は**売却時の時価ではなく、購入時の簿価**で計算されます。150万円で売却しても、復活する枠は100万円です。

**同じ年内には復活しない**

売却した枠が復活するのは、翌年1月以降です。同じ年内に売却と購入を繰り返しても、枠は復活しません。

たとえば、2025年3月に100万円分を売却しても、2025年中は生涯投資枠の残高は増えません。2026年1月になって初めて100万円が復活します。

この仕組みについて詳しくは、[NISAで売却したら枠はいつ戻る？再利用のルールと簿価の考え方](/articles/nisa-baikyaku-waku-saikatsuyou/)で解説しています。


## 生涯投資枠の残高を確認する方法

実際に自分の生涯投資枠がいくら残っているかは、NISA口座を開設している金融機関のウェブサイトやアプリで確認できます。

**確認できる項目**

- これまでに購入した金額の合計（簿価ベース）
- 生涯投資枠の残高（1,800万円 - 購入額）
- 成長投資枠の残高（1,200万円 - 成長投資枠での購入額）
- 年間投資枠の使用状況（つみたて投資枠120万円、成長投資枠240万円）

金融機関によって表示される項目名や画面の構成は異なりますが、「NISA口座」「生涯投資枠」といったメニューから確認できることが多いです。

**定期的に確認する理由**

- 年間投資枠を使い切ったかどうかを確認する
- 成長投資枠の1,200万円上限に近づいていないかを確認する
- 売却した枠が翌年に復活したかを確認する

特に、成長投資枠で個別株や一括購入を行う場合は、1,200万円の上限を超えないよう残高を確認しながら投資することが大切です。

成長投資枯で一括投資する際の注意点は、[成長投資枠で一括投資するときの注意点｜上限と購入時期の考え方](/articles/seicho-toushiwaku-ikkatsu-chuui/)で詳しく解説しています。


## 購入・売却の履歴で変動する生涯投資枠の例

実際に、購入と売却を繰り返した場合、生涯投資枠の残高がどう変動するかを具体例で見てみましょう。

**例：つみたて投資枠と成長投資枠を併用**

| 年 | 取引 | 購入額（簿価） | 売却額（簿価） | 生涯投資枠の残高 |
|---|---|---|---|---|
| 2024年1月 | 開始時 | - | - | 1,800万円 |
| 2024年中 | つみたて投資枠で120万円購入 | 120万円 | - | 1,680万円 |
| 2025年中 | つみたて投資枠で120万円購入 | 120万円 | - | 1,560万円 |
| 2026年中 | 成長投資枠で300万円購入 | 300万円 | - | 1,260万円 |
| 2027年中 | 2024年購入分を売却（時価150万円） | - | 120万円 | 1,260万円（年内は変わらず） |
| 2028年1月 | 売却分が復活 | - | - | 1,380万円（120万円復活） |

この例では、2027年に売却しても、同じ年内は生涯投資枠の残高は変わりません。翌年2028年1月になって初めて、売却した簿価分（120万円）が復活します。

**成長投資枠の上限にも注意**

上の例で、2026年に成長投資枠で300万円を購入しました。成長投資枠の残高は1,200万円 - 300万円 = 900万円です。

もし2027年に売却した120万円が成長投資枠で購入したものであれば、2028年1月に成長投資枠の残高も120万円復活します。

生涯投資枠と成長投資枠の内訳を意識しながら投資計画を立てることが大切です。詳しくは、[新NISAの1,800万円の内訳｜成長投資枠1,200万円までのルールと使い方](/articles/nisa-1800-uchiwake/)も参考にしてください。


## 簿価管理の仕組みを理解しておくべき理由

なぜ生涯投資枠が簿価で管理されるのか、その理由を理解しておくと、投資計画を立てやすくなります。

**理由①：枠の管理がシンプルになる**

もし生涯投資枠が時価で計算されると、株価や基準価額が変動するたびに枠の残高が変わってしまいます。これでは投資家も金融機関も管理が複雑になります。

簿価で管理することで、「購入した金額の合計」というシンプルなルールで枠を把握できます。

**理由②：売却時の枠の復活がフェア**

売却時の時価で枠が復活すると、値上がりした人ほど多くの枠を再利用できることになり、公平性に欠けます。

購入時の簿価で復活することで、誰にとっても同じルールが適用されます。

**理由③：長期投資を促す制度設計**

簿価で管理されることで、短期的な値動きに一喜一憂せず、長期で保有する投資スタイルが推奨されます。

値上がりしても枠が減らないため、「含み益が出たら早く売却しなければ」といった焦りが生まれにくい仕組みです。

新NISAの制度設計や恒久化の意味については、[新NISAは無期限で恒久化｜期限がないことの意味と長期投資の注意点](/articles/nisa-muki-gen-permanent/)で解説しています。


## 生涯投資枠を計画的に使うためのチェックリスト

生涯投資枠を効率的に使うために、確認しておきたいポイントを整理します。

**投資を始める前に確認すること**

- [ ] 生涯投資枠は簿価で管理されることを理解した
- [ ] 成長投資枠は1,200万円までという上限を確認した
- [ ] 年間投資枠（つみたて120万円、成長240万円）を確認した
- [ ] 自分がどの枠をどのくらい使うか、方針を決めた

**投資を続ける中で確認すること**

- [ ] 定期的に生涯投資枠の残高を確認している
- [ ] 成長投資枠の残高を確認し、1,200万円を超えないよう注意している
- [ ] 売却した場合、翌年に枠が復活することを理解している
- [ ] 年間投資枠を使い切ったかどうかを年末に確認している

年間投資枠の繰り越しについては、[新NISAの年間投資枠は繰り越せる？使い切れなかった枠の扱いと生涯枠の考え方](/articles/nisa-nenkan-waku-fukusuu-nen/)で詳しく解説しています。

**よくある誤解を避ける**

- 時価が上がっても枠は減らない → 簿価で計算される
- 時価が下がっても枠は戻らない → 簿価で計算される
- 売却した年内に枠は復活しない → 翌年1月以降に復活
- 成長投資枠を1,200万円まで使わなくてもよい → 投資方針次第


## まとめ｜生涯投資枠は簿価で管理され、売却で翌年以降に復活する

新NISAの生涯投資枠1,800万円は、購入時の取得価額（簿価）で管理されます。資産が値上がりしても値下がりしても、枠の残高は購入した金額の合計で計算されます。

成長投資枠は1,200万円までという上限があり、残りはつみたて投資枠と成長投資枠で1,800万円まで使えます。

売却すると、その簿価分の枠が翌年以降に復活し、再利用できます。同じ年内には復活しないため、売却のタイミングを計画する際は注意が必要です。

生涯投資枠の残高は、金融機関のウェブサイトやアプリで定期的に確認し、自分があといくら投資できるかを把握しておきましょう。
