# ASP登録・アフィリエイト提携ガイド（初心者向け）

このサイトの収益の入口は、**ASP（アフィリエイトサービスプロバイダ）経由の証券口座開設の成果報酬**です。
この手順書は、ASPに登録して、証券会社との提携が承認されたら、リンクを貼るところまでをまとめたものです。

> 2026-09-20 時点の調査にもとづきます。ASPごとの取扱い・報酬・審査基準は変わります。**必ず各ASPの管理画面で最新の条件を確認してください。**

---

## 0. 申請する前に整っているか（チェックリスト）

ASPの審査は、サイトの中身も見られます。次が揃っていると通りやすくなります（公式の合格基準ではなく、一般的な目安です）。

- [ ] サイトが公開されていて、誰でも見られる
- [ ] 記事が10本前後ある（このサイトは公開日が来ると順次増えます。10月上旬には十数本になります）
- [ ] 運営者情報（名前・プロフィール）がある → `/about/`
- [ ] プライバシーポリシー・免責事項・広告について（PR表記）がある → 設置済み
- [ ] 連絡先がある（メールアドレス、またはお問い合わせフォーム）→ 下の「1. 連絡先」を参照

## 1. 連絡先を用意する（推奨）

個人のメールアドレスを公開したくないときは、**Googleフォーム**が無料で使えます。

1. https://docs.google.com/forms で新しいフォームを作る（項目: お名前・メールアドレス・お問い合わせ内容）
2. 右上の「送信」→ リンクのアイコン → URLをコピー
3. GitHubで `config/site.yaml` を開いて鉛筆マークで編集し、`contact_email: ""` の行の下に次の1行を足す

```yaml
  contact_url: "https://forms.gle/xxxxxxxx"
```

4. Commit changes → Actions の daily-publish を手動実行 → 「運営者情報」ページに「お問い合わせフォーム」が出ればOK

## 2. 登録するASP（無料）

証券口座の案件は、ASPごとに扱いがちがいます。まず次の2〜3社に登録するのがおすすめです。

| ASP | ひとこと |
|---|---|
| **A8.net** | 国内最大手。登録は無料で、広告主（証券会社など）ごとに提携申請をする |
| **アクセストレード** | 金融系の案件が多い。SBI証券などの取扱いが確認されている（第三者情報） |
| **TGアフィリエイト** | 楽天証券の公式ページが、提携先として案内している |

調べた内容（2026-09-20時点）:

- **楽天証券**の公式ページ（アフィリエイトプログラム）では、提携先のアフィリエイト会社を経由して申し込む形で案内されています。
- **SBI証券**は、第三者の調査ブログでは TGアフィリエイト・アクセストレードが対応とされています（公式ページには一覧の記載を確認できませんでした）。
- **マネックス証券**は、アクセストレードにあるとする情報があります。

**確認方法:** ASPに登録したら、管理画面の「プログラム検索（広告主検索）」で、「SBI証券」「楽天証券」「マネックス証券」と検索します。あれば、その画面に提携条件と報酬が出ます。

## 3. 提携を申請する

1. ASPにログインして、メディア（サイト）を登録する
   - サイトURL: `https://fc4405.github.io/nisa-data-room/`
   - サイト名: NISAデータ室
   - カテゴリ: 金融・投資（NISA）
2. 検索して見つけた証券会社のプログラムに、「提携申請」をする
3. サイトの説明文は、次の例を、ご自身の言葉に直して使えます

> 新NISAの制度・口座選び・積立を、金融庁などの一次情報と自動更新データで整理するサイトです。制度の解説記事、積立シミュレーター、株価指数の自動更新データを掲載しています。特定の銘柄は推奨せず、口座選びの基準の解説の中で、証券会社の公式サイトへの案内を掲載する予定です。

4. 審査結果は、数日〜1週間ほどで、メールと管理画面に届くことが多いです

**落ちても再申請できます。** A8.netのヘルプでは、審査に落ちたプログラムにも再度申し込めるが、サイト自体が広告主の条件を満たさないと、再度見送りになる可能性がある、と説明されています。落ちたときは、記事を増やし、サイトを整えてから、再申請しましょう。

## 4. 守ること（とても大切）

証券口座は、**金融商品取引法**などの規制がある分野です。楽天証券の公式ページにも、外務員登録がない場合は、「証券取引の勧誘や個別商品の説明等の行為をされないようご注意ください」という趣旨の案内があります。

このサイトでは、次のルールで運営しています。これを崩さないでください。

- 個別の銘柄・商品の**売買を勧めない**（品質ゲートで機械的にも検査しています）
- 「必ず儲かる」「損しない」など、**断定・保証の表現を使わない**
- 広告であることを**明示する**（PR表記は自動で付きます）
- **報酬額やキャンペーンの数値を、記事に書かない**（変わりやすく、古いと問題になり得るため）
- 各証券会社・ASPの**広告掲載ガイドライン**に従う（承認後に、ASPの管理画面で確認できます）

※ この文書は法律的な助言ではありません。判断に迷うときは、ASPの担当窓口や、専門家に確認してください。

## 5. 承認されたら: リンクを貼る（1分）

1. ASPの管理画面で、承認されたプログラムの「広告リンク」（テキストリンクのURL）をコピーする
2. GitHubで `config/affiliates.yaml` を開き、鉛筆マークで編集
3. 該当の証券会社の `affiliate_url: ""` の引用符の間に、コピーしたURLを貼る

```yaml
  sbi:
    name: SBI証券
    official_url: https://www.sbisec.co.jp/
    affiliate_url: "ここに貼る"
```

4. Commit changes → Actions の daily-publish を手動実行
5. サイトの「新NISA口座はどこで開く？」の記事に、ボタン（PR表示つき）が出ればOK

## 6. Googleに登録する（Search Console）

検索から人が来るために、必要な作業です。

1. https://search.google.com/search-console を開く
2. 「プロパティタイプ」で **URLプレフィックス** を選び、`https://fc4405.github.io/nisa-data-room/` を入力
3. 確認方法で **HTMLタグ** を選ぶ → `<meta name="google-site-verification" content="ここの値" />` の**content の中身だけ**をコピー
4. `config/site.yaml` の `google_site_verification: ""` の引用符の間に貼る → Commit → daily-publish を手動実行
5. Search Console に戻って「確認」を押す
6. 左メニュー「サイトマップ」に `sitemap.xml` を入力して送信

## 7. 収益が出るまでの目安

| 時期 | やること・起きること |
|---|---|
| 今〜1週間 | 連絡先を用意、Search Console登録、ASP登録と提携申請 |
| 1〜2か月 | 記事が増える。検索に載り始める（アクセスはまだ少ない） |
| 2〜4か月 | 少しずつ検索流入が出る。最初の成果（口座開設）が出る可能性がある |
| 6〜12か月以上 | 記事・アクセスが育つと、月数万円が見えてくる可能性がある（届かないこともある） |

焦らず、**毎週の `reports/weekly.md`** を見て、伸びている記事に近いテーマを増やしていく運用です。
